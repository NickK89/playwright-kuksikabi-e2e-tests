# 🍣 Playwright E2E Automation Framework (Python & JavaScript)

Автоматизированный E2E-фреймворк для тестирования пользовательского сценария оформления заказа (самовывоз) на сайте ресторана азиатской кухни **Кукси Каби**. 

Проект реализован в двух зеркальных версиях на **Python (Pytest)** и **JavaScript (Node.js)** с применением современных практик QA Automation.

---

## 🛠 Технологический стек и архитектура

* **Языки и фреймворки:** Python 3 + Pytest / JavaScript (Node.js) + Playwright Test.
* **Паттерн проектирования:** **Page Object Model (POM)** — полное разделение логики тестовых сценариев и UI-локаторов (`CartPage`).
* **Отчетность и отладка:** Автоматическая запись видео прохождения тестов (`--video on`), снятие полноразмерных скриншотов формы заказа, конфигурация через `pytest.ini` и `playwright.config.js`.

---

## 💡 Решенные инженерные задачи (Real-world Challenges)

В ходе разработки тестов на живом коммерческом сайте были выявлены и успешно обойдены следующие особенности верстки и защиты:

1. **Конфликт дублирующихся локаторов (Strict Mode Violation):** 
   На странице корзины поля ввода (`phone`, `email`) и чекбоксы согласий (`#politic`) продублированы в скрытых модальных окнах бронирования. Проблема решена с помощью **каскадных локаторов**, жестко привязанных к родительскому контейнеру формы заказа (`.oformlenie-rightblock`).
2. **Зацикливание автоскролла (Infinite Scroll):** 
   Фиксированная «прилипающая» шапка сайта перекрывает элементы в нижней части экрана, из-за чего стандартный механизм *scroll-into-view* в Playwright уходит в бесконечный цикл. Проблема устранена использованием принудительных действий (`force=True`) и прямым опросом DOM-свойств кнопки отправки через `page.evaluate()`.
3. **Защита от блокировок (Anti-Bot / WAF Evasion):** 
   Настроена эмуляция реального пользователя: подмена заголовков `User-Agent`, установка локали (`ru-RU`) и часового пояса, удаление флага автоматизации `navigator.webdriver`, а также регулировка скорости действий через `slowMo`.
4. **Оптимизация сетевых ожиданий:** 
   Для защиты от медленной загрузки сторонних скриптов аналитики применена стратегия `wait_until="commit"` с увеличенным таймаутом.

## 🚀 Инструкция по запуску

### 1. Запуск версии на Python

Перейдите в директорию Python-проекта, активируйте виртуальное окружение и установите зависимости:

```bash
cd kuksi-tests-py
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Установка Playwright и браузеров:
pip install pytest-playwright
playwright install
```

Запуск теста (все флаги `--headed`, `--slowmo` и `--video` уже настроены в `pytest.ini`):
```bash
python -m pytest test_kuksi.py
```

---

### 2. Запуск версии на JavaScript

Перейдите в директорию JS-проекта и установите пакеты:

```bash
cd kuksi-tests-js
npm install
npx playwright install
```

Запуск теста (настройки эмуляции и записи видео подтянутся из `playwright.config.js`):
```bash
npx playwright test
```
